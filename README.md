# Para Você 💘
Abra `index.html` no navegador (funciona sem servidor). Login: usuário e senha em `js/config.js`, junto com a data de início, a assinatura e a lista de fotos.
- `estilo.css` – visual · `js/app.js` – interações · `js/heart3d.js` – coração 3D · `vendor/three.min.js` – Three.js local
- `img/t/` – miniaturas otimizadas (as fotos originais `fotoN.jpg` são usadas na ampliação)
